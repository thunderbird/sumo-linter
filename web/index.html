    Everything runs in your browser. Your markup is never uploaded, so unpublished drafts stay private. It is saved in this browser as you type and comes back when you reopen the page, until you press Clear. On a shared computer, press Clear when you finish.

    House style normalises headings to whichever style the article already uses most, so a consistent article is left exactly as it is. Nothing is rewritten just to look tidy — every source change is reviewed by volunteer localizers.

    Applying safe fixes in bulk only touches repairs whose intent is certain. A repair marked needs review is a guess — most markup errors have several plausible corrections — so it is never applied in bulk, but you can apply one from its own Fix button and check the result. Every fix is undoable with the usual keystroke.

    Save to file saves the markup as a .wiki file, which the SUMO modes for VS Code, Emacs and Vim open. In Chrome and Edge you choose the file once, and the page then saves every change to it until you close the tab. Firefox and Safari cannot do that, so each click downloads a new copy.

    Preview shows roughly how SUMO will render the article. Templates, images and videos are placeholders, and article links have no target, because the page cannot fetch from SUMO. Choose a system and a Thunderbird version to see only the {for} content for them, as a reader would. Show all shows every branch, labelled. Use Show to hide the Preview or Problems column.
